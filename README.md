# Media Downloader

A universal media downloading utility built for personal archiving, educational research, and offline accessibility.


<img width="848" height="373" alt="Sprite-0001" src="https://github.com/user-attachments/assets/dba0d073-a19f-4a85-a774-bea2e32ae094" />


## How to Use

1. **Download the App:** Go to the [Releases](../../releases) page and download the latest `.exe` installer.
2. **Install:** Run the installer and launch Media Downloader.
3. **Copy a Link:** Copy the URL of the video, audio, or document you want to download from your browser.
4. **Paste and Fetch:** Paste the link into the application and click **Download** (or click the settings icon to choose a specific format). 
5. **Start Download:** The app will fetch the media and save it to your default downloads folder!
